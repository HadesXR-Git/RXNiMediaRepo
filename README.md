# RXN iMedia Repository

> Web-ready e-learning content published by RXN Research&Dev.

The **RXN iMedia Repository** is a web-accessible repository for published HTML content created with **Articulate Storyline 3** and **iSpring**.

Its purpose is to make published learning media accessible across different devices through a standard web browser.

## Access

Published content is hosted through **GitHub Pages** and can be accessed using the web address provided for each individual project.

**GitHub Repository:**  
https://github.com/HadesXR-Git/RXNiMediaRepo

**GitHub Pages:**  
https://hadesxr-git.github.io/RXNiMediaRepo/

## Cross-Device Access

The published content is designed to be accessible from a variety of web-capable devices, including:

- Smartphones
- Tablets
- Laptops and desktop computers
- Other modern web-capable devices

No installation of the original authoring software is required to view the published web content.

## Supported Authoring Platforms

The repository primarily contains web-ready output published from:

- **Articulate Storyline 3**
- **iSpring**

The repository stores the **published web output** and its required supporting files rather than the original authoring project files.

## Content

Published projects may contain:

- HTML files
- JavaScript
- Images and graphics
- Audio and video
- Interactive learning elements
- Other supporting web assets

Each published project is generally kept within its own directory
along with the files required for it to function correctly.
